# Zaiken — جاهز للتشغيل

## التشغيل
1. ثبّت Node.js LTS من https://nodejs.org/
2. فك الضغط
3. شغّل **start.bat** (Windows) أو `./start.sh`

## ما يعمل حالياً
- جلسات لعب: Launch → End Session يحفظ الوقت ويمنح XP
- إنجازات تلقائية عند المباريات / الجلسات / تقارير AI
- Overlay حي: CPU و RAM و Ping و GPU (NVIDIA إن وُجد) + K/D و Win Rate
- مدرب AI محسّن (عربي/إنجليزي) مع اختصارات سريعة
- مراقبة سجلات اللعبة + عرض هاشات SHA-256
- لون الواجهة (Accent) يُطبَّق فوراً من الإعدادات

## معطّل عمداً
**البطولات (Tournaments):** معطّلة مؤقتاً بانتظار خلفية حقيقية (backend)، حماية ضد الغش، ومراجعة قانونية.

**المتجر / المحفظة:** معطّل مؤقتاً بانتظار دفع حقيقي (مثل Stripe) ومراجعة قانونية. لا تُعاد أزرار «أضف رصيد تجريبي» كأنها شراء حقيقي.  
لا تُعاد كبيانات وهمية أو جوائز نقدية محلية.
